# Gap Analysis
## Our Current Situation
Aleena and I's skills are pretty similar in terms of technologies. We are both familiar in a multitude of languages including Java, C#, HTML/CSS, Javascript, and C, as well as other technologies such as Git and the Unity game engine. I have a little more experience in languages like Python and Typescript but other than that me and Aleena are fairly on par. We both want to learn C++ and how game engines as a whole function.

## Our Goals
As C++ is a common language used in game dev jobs, we want an excuse to be able to work on a project using it. As we are both in game dev, we believed the best project to do this would be the Godot game engine because it also feeds into our second goal of wanting to see how these engines work.

## Our Gaps
Our main concern with this project is that we both have very minimal experience with C++. I only briefly learned it in a class but desire to get more comfortable with it. The same goes for Aleena. While we do have experience working in other game engines, we do not have experience working in godot specifically which may prove to be an obstacle as well.

## Our Plan
We plan on first taking a look at the Godot repository to see what issues we can feasibly work on and then learning the skills necessary for those issues. Next, we'll learn the syntax for C++ and build small projects using it. Thankfully, Godot supports developing with C++ so we can use this as an opportunity to learn the game engine AND brush up on C++ at the same time.
