# Project Review

## Getting Started
FreeCodeCamp provides a Discord server to chat with other contributors along with an FAQ, and a forum. For learning new technologies, their YouTube channel provides videos on learning these technologies.
### Documents
FreeCodeCamp provides [this](https://contribute.freecodecamp.org/getting-started/#ui--client) for getting started to code. Very well formatted document with extensive guideline of how to set up your environment with links leading to how to contribute to different parts of the project like their codebase, coding challenges, quizzes, etc. Overall, this guideline is very clear.

### Code of Conduct
[Code of Conduct](https://www.freecodecamp.org/news/code-of-conduct)

The given Code of Conduct is very simple as its message is "Be nice. No harassment, trolling, or spamming.". As a newcomer, it doesn't seem intimidating at all.
### User Installation
For using this product as a user, it is really simple as it is a web based platform.

### Developer Installation
[Developer Installation](https://contribute.freecodecamp.org/how-to-setup-freecodecamp-locally/)

FreeCodeCamp has very detailed steps with multiple ways to configure your setup either with GitHub codespaces or on your local machine. The steps seem very easy to follow along with the list of commands associated with their function.

### Organization
The documents were easy to find as well as easy to figure out their purpose. They make it such that the amount of information isn't overwhelming and it looks very modern.

### Summary
Based on the details provided, FreeCodeCamp seems to be a welcoming and a user-friendly experience. Documentation is very easy to follow as a newcomer, as it is complete written at a very simple level.
