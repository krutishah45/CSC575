### Sugar Labs

#### Project Repository:
https://github.com/sugarlabs

#### Project HomePage:
https://www.sugarlabs.org/

#### Product:
Sugar Labs is a non-profit organization that supports Sugar, an open-source learning platform whose mission is to empower children to "learn to learn" through creative, collaborative, and constructionist educational activities.

#### Target User Community
Sugar Labs is primarily developed for chidlren aged 5-12 serving educators, students, and schools particularly in developing regions.

#### Activity
Pretty active, looking at the musicblocks repo, the last commit was 17 hours ago with 9,991 commits as of 2/24/2026.

#### Getting Started
Sugar Labs provides a guide for contributing code and specific guides for how to contribute for their indivudal sugar labs products on how to set up your machine for development as well as how to run the product in general.

#### Welcoming to Newcomers
For newcoming developers, Sugar Labs seems to be very welcoming to developers of all experiences with many issues labelled as "good first issues".
