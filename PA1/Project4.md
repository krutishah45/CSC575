# Project Exploration: 

## Project Title: 
Blender

## Project Repository: 
https://projects.blender.org/blender/blender

## Project Homepage: 
https://www.blender.org/

## Product: 
Blender is a popular 3D modeling software that allows users to create various models with high detail.

## Target User Community: 
Blender's target audience is 3D modelers, game developers, animators, and anyone who has a need to create a 3D model. It serves a purpose of allowing users to create models that may be necessary for whatever they are working on. 

## Activity: 
There is almost an entire page of commits made in the last 24 hours. There were also several pull requests opened or closed today. Many issues were also opened or closed today. This is a very active project.

## Getting Started: 
The documentation was easily accessible, with very easy to find guides for new developers and code navigation readily available within their documentation handbook (https://developer.blender.org/docs/handbook/). There is also a developer forum that is easily accessible from the README on their repository site. 

## Welcoming to Newcomers: 
They have a "GoodFirstIssue" label in their issue tracker. The developer handbook also has easy to find information specifically to help newcomers get on board. It seems like a welcoming project, especially for how large it is. The forum is also easy to access, so I would feel welcomed trying to get started on this project.
