# Project Exploration
## Project Title:
vscode

## Project Repository:
https://github.com/microsoft/vscode

## Project Homepage:
https://code.visualstudio.com/

## Product:
VS Code is a free, lightweight code editor designed for coding a wide range of software. It features powerful code editing features such as syntax highlighting, intelligent code completion, built-in Git source control and an integrated terminal. 

## Target User Community:
VS Code is used by a broad developer community, from beginners to professional software engineers across a myriad of different programming languages. This addresses a need for a powerful yet flexible code editor that can be used for many different purposes.

## Activity:
182k stars, 38k forks, thousands of open and ongoing issues and discussions, hundreds of pull requests, hundreds of thousands of commits

## Getting Started:
Finding documentation for starting in VS Code was a breeze. Files like its CONTRIBUTING.md, its wiki, and the rest of its documentation is perfect for anyone starting out.

## Welcoming to Newcomers:

## Getting Started
   
### Documents
[README](https://github.com/microsoft/vscode/blob/main/README.md)
[CONTRIBUTING](https://github.com/microsoft/vscode/blob/main/CONTRIBUTING.md)
[Templates for requesting features/reporting bugs](https://github.com/microsoft/vscode/tree/main/.github/ISSUE_TEMPLATE)
The README is the big ticket here. It has many links and tutorials of what to contribute, how to install, how to request for features or bug fixes, etc. 

### Code of Conduct
[CODE OF CONDUCT](https://opensource.microsoft.com/codeofconduct/)
Through this code of conduct, it paints the vscode contribution community as an inclusive, responsible place.
   
### User Installation
[SETUP GUIDE](https://code.visualstudio.com/docs/setup/setup-overview)
This link makes it trivial for setting up vscode regardless of platform or skill. 

### Developer Installation
[CONTRIBUTION GUIDE](https://github.com/microsoft/vscode/wiki/How-to-Contribute)
This is vscode's contribution wiki. It lists a lot of information about how to start developing. 

### Organization
The organization of the project is mostly good. There were a few documents that were a bit trickier to find than others but with a little digging they aren't too difficult to find. Information is displayed nicely, includes a lot of detail, and is up to date. 

### Summary
Overall, I believe that Vs Code would be a great place to start. Documentation is clear and easy to understand, the wiki is super detailed and there are thousands of people working on it every day.
