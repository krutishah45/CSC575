# Project Exploration
## Project Title:
vscode

## Project Repository:
https://github.com/microsoft/vscode

## Project Homepage:
https://code.visualstudio.com/

## Product:
VS Code is a free, lightweight code editor designed for coding a wide range of software. It features powerful code editing features such as syntax highlighting, intelligent code completion, built-in Git source control and an integrated terminal. 

## Target User Community:
VS Code is used by a broad developer community, from beginners to professional software engineers across a myriad of different programming languages. This addresses a need for a powerful yet flexible code editor that can be used for many different purposes.

## Activity:
182k stars, 38k forks, thousands of open and ongoing issues and discussions, hundreds of pull requests, hundreds of thousands of commits

## Getting Started:
Finding documentation for starting in VS Code was a breeze. Files like its CONTRIBUTING.md, its wiki, and the rest of its documentation is perfect for anyone starting out.

## Welcoming to Newcomers:
There are "good first issue", CONTRIBUTING.md, and a comprehensive contributing wiki page. 

## Personal Interest:
I thought this project would be good to work on because of how familiar we all are of VS Code. It's a big enough project where there are bound to be both issues to be fixed as well as good documentation to help us fix them.

## Skills Match:
VS Code is primarily made in Typescript which I am fairly familiar with, but I could always use a brush up on!

## Other:
Its a very popular repo and it has corprate backing giving it strong stability and community involvement.

## Aleena: 
I'm not opposed to learning Typescript, but I've never used it before, and I feel like I have more reason to learn C++ than Typescript, so if I'm going to work on something in a language I haven't used before I'd gravitate toward something in C++.
