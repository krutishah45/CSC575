## Product:
VS Code is a free, lightweight code editor designed for coding a wide range of software. It features powerful code editing features such as syntax highlighting, intelligent code completion, built-in Git source control and an integrated terminal. 

## Target User Community:
VS Code is used by a broad developer community, from beginners to professional software engineers across a myriad of different programming languages. This addresses a need for a powerful yet flexible code editor that can be used for many different purposes.

## Activity:
