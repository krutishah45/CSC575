# Project Exploration
## Project Title:
Aseprite

## Project Repository:
https://github.com/aseprite/aseprite

## Project Homepage:
https://www.aseprite.org/

## Product:
Aseprite is a tool used to create and edit 2D pixel art and animation. It supports layers, frames, animation previews, onion-skinning, and many more features that artists would use.   

## Target User Community:
This project would mostly be used for pixel artists and game developers. They can create high quality 2D pixel sprites and animations very easily. This project addresses the need for an art creation tool solely built around 2D pixel art and offers tools specifically for it.

## Activity:
Aseprite is an incredibly popular repo with 35.5k stars and 7.7k forks. Issues are very commonly added to the repo and the repo itself is being updated constantly. 

## Getting Started:
Documents like CONTRIBUTING.md and INSTALL.md are the best places to start when you start out developing for Aseprite. Besides the documentation, Aseprite does have an active community on Discord.

## Welcoming to Newcomers:
Aside from the documentation illustrated in the previous section, there is an incredibly supportive and welcoming community that is willing to help anyone starting out. There are tags for good first issues but it doesn't seem to be used very much.
