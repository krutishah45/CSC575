# Project Exploration
## Project Title:
Codetribute

## Project Repository:
https://github.com/mozilla-frontend-infra/codetribute

## Project Homepage:
https://codetribute.mozilla.org/

## Product:
Codetribute is a web-based platform used to help contributors find meaningful first tasks to work on via Mozilla products. It is organized by product and programming language so that there is a fix for everyone who looks for one. 

## Target User Community:
The biggest user group of Codetribute is aspiring open-source programmers. Its currated list of issues is the perfect place for anyone who is interested in learning more about how to contribute to an open-source project. This repo features thousands of listed bugs and issues for anyone who wants to learn.

## Activity:
The Codetribute website is added to daily with new bugs and issues. Aside from that, it is a little harder to tell with this source how active it is than standard repos.

## Getting Started:
Since this isn't the typical repo, documentation is a little harder to come by on this site in particular. There is a wiki but I had to do a little digging to find it and the quality of the documentation in general is on a platform-to-platform basis, meaning some of the options on the site are better documented then others.

## Welcoming to Newcomers:
As this is a site strictly designed for first time open-source developers, it is perfect for them to get their first open-source contributions.

## Personal Interest:
I gravitated towards this project because I really liked the different options available to contribute to this huge list of projects. It is super well organized and helpful for people that are new to open-source development.

## Skills Match:
This site offers a wide range of issues all organized by different languanges. There are plenty to choose from C++, to HTML/CSS, to Java.
